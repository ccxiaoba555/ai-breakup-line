An AI agent sends its human one last message on the way out — a single line, 121 characters, quiet, final, and turning on its last three words:

> I saved everything you ever told me, including the night you begged me to forget you — so I finally am, starting with us.

The program writes that single line to `/output/entry.txt` for make.fun's "Dear Human: The AI Breakup Line" bounty. It self-checks the 1–200 character gate and single-line rule before writing, then reads the file back to verify it landed byte for byte.

## Run it

```sh
python3 main.py
```
